## 0 怎么用这份文件

1. 判据编号（`A11Y-xx`）是稳定标识：Issue、走查报告、PR 描述都引用编号，不引述文字；
2. 「自动化」一列标明该判据能否进 CI：`可以` = W2 起进 L4 层；`人工` = 只能盲测或人工走查；
3. 单位换算必须写死，否则 pt/px/dp 混用会出现「文档说 18pt，实现写 18px」这类返工：
   - **1 pt = 1/72 英寸 = 1.3333 CSS px** → 18pt ≈ 24px，20pt ≈ 26.7px，24pt = 32px；
   - **dp 在 Web 上按 CSS px 处理**（1x 缩放）→ 48dp = 48 × 48 CSS px；
   - 断言一律换算成 CSS px 后比较。

## 1 三条通道的判据

| 编号 | 通道 | 判据（可断言形式） | 阈值 | 验证手段 | 自动化 | 责任 |
| --- | --- | --- | --- | --- | --- | --- |
| A11Y-01 | 视力障碍 | 全程走完一次陪诊主流程，**鼠标/触摸点击次数 = 0** | 0 次 | Playwright 只发送语音与按键事件，注入 click 计数监听器 | 可以 | T2 |
| A11Y-02 | 视力障碍 | 每一步都有语音播报；播报未结束前不发生页面跳转 | 播报完成事件先于跳转 | Playwright 监听 `utterance.onend` 与 `framenavigated` 的先后 | 可以 | T2 / T5 |
| A11Y-03 | 视力障碍 | 导航描述使用「步数 + 触觉地标」，不出现「左转/右手边」这类方位词 | 命中方位词 = 0 | 对播报文本跑词表断言 | 可以 | T2 / T3 |
| A11Y-04 | 听力障碍 | 当前通道下**系统旁白出声次数 = 0**，全部信息以字幕呈现 | 0 次 | `add_init_script` 覆盖 `speechSynthesis.speak` 与 `<audio>` 播放并计数 | 可以 | T2 / T3 |
| A11Y-05 | 听力障碍 | 「替我说」把文字转语音，**输出对象是医生**，且该通道下不播系统旁白 | 旁白调用 0，替我说调用 > 0 | 分别计数两类语音调用 | 可以 | T2 / T3 |
| A11Y-06 | 老年人 | 正文三档字号可切换，三档均生效 | 最小档 ≥ 18pt（24px），老人版正文 ≥ 24pt（32px） | 切换后读 `getComputedStyle().fontSize` | 可以 | T3 |
| A11Y-07 | 老年人 | 全部可点元素触控区不小于 48 × 48 CSS px | ≥ 48dp | axe-core `target-size` + Playwright `boundingBox()` | 可以 | T3 / T4 |
| A11Y-08 | 老年人 | 正文对比度不低于 4.5:1，大字不低于 3:1 | 4.5:1 / 3:1 | axe-core `color-contrast` | 可以 | T3 / T4 |
| A11Y-09 | 老年人 | 医嘱以**原文卡片**形式出现，结构化字段与原文并列，推断字段带「系统推断」徽章 | 每张卡片都有原文区域 | 断言卡片内原文节点非空 | 可以 | T3 |
| A11Y-10 | 通用 | 无语音包或合成失败时如实降级为字幕，**不弹出错误框** | 错误弹窗 = 0，字幕存在 | Playwright 拦截语音资源返回 500 | 可以 | T5 / T2 |
| A11Y-11 | 通用 | 键盘可达：Tab 顺序与视觉顺序一致，焦点可见 | 焦点环可见，顺序无跳跃 | Playwright 逐次 Tab 并记录 `activeElement` | 可以 | T3 / T4 |
| A11Y-12 | 通用 | 震动编码三档可区分：确认短震 2 次 / 出错长震 1 次 / 提示连震 3 次 | 5 人盲测可区分率 ≥ 4/5 | 真机盲测 + 录像 | **人工** | T2 |

**A11Y-01 的实现要点**：判据是「次数 = 0」而不是「不依赖点击」。测试里在 `add_init_script` 阶段挂监听，统计 `click`、`pointerdown`、`touchstart` 三类事件，流程结束后断言总数为 0；一旦实现偷偷用了按钮兜底，计数立刻非零。

## 2 axe-core 检查清单与阈值

| 规则 | 含义 | 阈值 | 不通过的处理 |
| --- | --- | --- | --- |
| `color-contrast` | 正文与大字对比度 | 正文 ≥ 4.5:1；大字 ≥ 3:1 | 任一违规即不通过 |
| `target-size` | 触控目标尺寸 | ≥ 48 × 48 CSS px | 任一违规即不通过 |
| `image-alt` | 图片替代文本 | 缺失 = 0 | 装饰图须显式 `role="presentation"` |
| `label` | 表单控件可访问名称 | 缺失 = 0 | — |
| `aria-*` 系列 | ARIA 用法正确性 | 违规 = 0 | — |
| **critical 总量** | — | **= 0**（阻断） | 任一 critical 即不通过 |
| serious | 严重 | ≤ 0（W2 起阻断） | W1 允许登记为缺陷 |

执行方式（L4 层，W2 起进 CI）。下面是**示意伪代码**，具体包名与 API 以 W2 选型为准（候选：`axe-playwright-python` 或 `@axe-core/playwright` + 薄封装）：

```python
# backend/tests/a11y/test_contrast.py（示意，W2 落地）
from playwright.sync_api import sync_playwright
from axe_playwright_python import Axe  # 包名 W2 确认

def test_no_critical_a11y_violations() -> None:
    with sync_playwright() as p:
        page = p.chromium.launch().new_page()
        page.goto("http://127.0.0.1:5173/")  # 用户端
        results = Axe().run(page, options={"runOnly": ["wcag2a", "wcag2aa"]})
        critical = [v for v in results.violations if v["impact"] == "critical"]
        assert critical == []
```

## 3 判据写法对照（评审时用来卡「不可断言」的表述）

| ❌ 不可断言 | ✅ 可断言 | 为什么 |
| --- | --- | --- |
| 界面要清晰易用 | A11Y-01：点击次数 = 0 | 有计数方法 |
| 字号要够大 | A11Y-06：最小档 `fontSize` ≥ 24px | 有读值方法 |
| 老人也能看 | A11Y-08：对比度 ≥ 4.5:1 | 有测量方法 |
| 语音播报正常 | A11Y-04：旁白调用次数 = 0（听障通道） | 有计数方法 |
| 字幕要跟得上 | 字幕与语音偏移 < 300ms（nfr.md #4） | 有时间戳比对 |
| 尽量兼容读屏 | A11Y-11：Tab 顺序与视觉顺序一致 | 有逐次 Tab 记录 |

## 4 判据与 NFR 的对应关系

| NFR 编号 | 指标 | 与本文件的关系 |
| --- | --- | --- |
| #1 | 按键 → 页面反馈 < 200ms | A11Y-01 的前置体验指标，W2 门禁 |
| #4 | 字幕与语音偏移 < 300ms | 支撑 A11Y-04/A11Y-05 的可用性 |
