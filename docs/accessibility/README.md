## 三条使用规则

1. **判据只引编号**：Issue、PR、走查报告里写 `A11Y-04`，不要复述文字，避免多处表述漂移；
2. **写判据前先想怎么断言**：Playwright 能数就写次数，能读就读 `getComputedStyle`，能测就写毫秒；只能用眼睛判断的（如震动编码盲测）必须标「人工」；
3. **单位先换算再比较**：1 pt = 1.3333 CSS px，48dp = 48 CSS px。文档写 pt、断言写 px 是最常见的返工点。

## 判定权

无障碍达标性是 **V-01 否决权**，由 T2 与 T5 共同持有：凡在视障或听障模式下不可用的功能，任一方出具书面结论即为否决，修改后双方复核（10 号 §344）。
