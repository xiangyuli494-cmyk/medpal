评审须知

  1. 评审对象：本页面 + medpal-plan-v2/ 下 00、01、02、10、11、12、13、14、15、16 共 10 份文档。
  2. 评审重点：① 八周范围是否可完成 ② 每周任务包工作量与 4–8 小时投入是否匹配 ③ 角色分工是否均衡 ④ 里程碑验收标准是否过严或过松 ⑤ 有无遗漏的必须交付项。
  3. 提交方式：在项目群内以「文档编号 + 章节 + 意见」格式提出；或提 GitHub Issue 并标注 review 标签。
  4. 截止时间：项目启动会前一个晚上 22:00。逾期未提视为无异议。
  5. 裁决：T1 汇总意见，逐条标注「采纳 / 部分采纳 / 不采纳并说明理由」，形成评审纪要后冻结为执行基线。

二、八周时间线WEEKLY SCHEDULE

周任务包制：不设统一工作时段，投入时段由各人自行安排（每人每周 4–8 小时）。每周一 20:00 线上计划会下达任务包，每周日 24:00 前交付并附自测证据。每周仅三类固定会议：周计划会、双周评审会、里程碑评审会，其余全部异步。
