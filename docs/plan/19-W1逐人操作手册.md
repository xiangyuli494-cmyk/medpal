### 步骤 2 怎么处理 9 与 11

> **已裁决，照做即可**：系统状态机写 11 节点，对外演示讲 9 步，换算规则落在 `docs/specs/domain-model.md` §2.3。全库文字已按此统一。

背景：00 号、README、17 号原来说 9 个节点；02 号 §3.3 列了 11 个动作。两个数都在文档里，谁也没错，只是它们说的不是一回事：**一个是系统状态数，一个是用户感知的步骤数。**

裁决时采用的做法：

1. 状态机按 11 个写进枚举，因为每个动作都要发指令、要留痕，合并会丢细节；
2. 另写一张「11 → 9」的展示映射表，说明演示脚本怎么讲：把「看报告」并进「缴费取药」之后的说明，把「小结回家」当收尾动作，对外说 9 步；
3. 两处引用同步改，改完搜一遍全库，确认没有第三处还在说 9。**（已执行：全库现只有成员 D 原型的历史能力描述仍写「9 节点」，属正当保留）**

状态枚举命名统一用大写下划线，例如 ARRIVED、BRIEFING、REGISTER、WAITING、IN_ROOM、RECAP、PLAN_EXAMS、NAVIGATE、PAY_AND_PICKUP、REPORT、HOME。

### 步骤 3 的错误码，给一份起步清单

| 码 | 谁触发 | 设备端行为 | 重试 |
| --- | --- | --- | --- |
| E_AUDIO_TOO_SHORT | 设备端（< 0.5 秒） | 大字提示「再按住说一次」，不播报 | 是 |
| E_ASR_LOW_CONF | 服务端（置信度 < 0.6） | 复述听到的原文并问「是这个意思吗」 | 是，最多 2 次 |
| E_SESSION_EXPIRED | 服务端（30 分钟无跃迁） | 提示重新开始，保留时间轴 | 否 |
| E_TURN_OUT_OF_ORDER | 服务端（seq 跳号） | 静默请求重传，不打扰用户 | 是 |
| E_UPSTREAM_TIMEOUT | 适配器 | 先播兜底话术，再转人工 | 是，1 次 |
| E_QUOTA_LIMIT | 适配器（供应商限流） | 转人工，不重复调用 | 否 |
| E_CONSENT_REVOKED | 服务端（家属端撤回授权） | 家属通道无提示 | 否 |

### 步骤 4 的降级链，先给一组起始阈值

| 条件 | escalation | 说明 |
| --- | --- | --- |
| ASR 置信度 < 0.6，连续 1 次 | ask_again | 复述原文再问一次 |
| 同一问题连续 2 次没被理解 | call_staff | 转服务台，不再自问 |
| 用户说「我不懂」「我找不到」「我要找人」 | call_staff | 关键词命中即转，不看置信度 |
| 老人 90 秒没有任何输入 | call_family | 先提醒，再推送家属 |
| 跌倒、出血、疼痛自评 ≥ 7 | sos | 同时通知服务台与家属 |

这些数是**建议起始值**，写进文档时标一行「阈值待 W2 联调校准」。写死数字比写「视情况」强，因为后端能测，前端能断言。

### 步骤 5 的三个问题必须有答案

- 断线重连后从哪个 turn 接着播？答：从最后一个已确认送达的 turn + 1。
- seq 跳号怎么补？答：设备端保留最近 30 秒帧，服务端发 resend(from_seq)，设备端重发。
- 服务端消息保留多久？答：30 分钟。超过按 E_SESSION_EXPIRED 处理。

### 步骤 6 的 mock 服务骨架（参考，跑通再合）

依赖 websockets，写进 requirements-dev.txt，不要进生产依赖。W1 用 8090，W3 由 Django Channels 接 8000，届时删掉。

~~~python
import asyncio, json
import websockets

TURN = {
    "type": "turn_result", "session": "s_001", "turn": 1,
    "caption": {"text": "2 楼检验科，出电梯往左", "emphasis": ["2 楼", "往左"]},
    "speech": {"audio_url": "", "rate": 0.86, "can_interrupt": True},
    "device": {"vibrate": "confirm_twice", "haptic_after_ms": 1200},
    "flow": {"step": "navigate", "step_index": 8, "total": 11, "why": "抽血要空腹"},
    "escalation": {"level": "none"},
    "confidence": {"asr": 0.91, "intent": 0.88},
}

async def handler(ws):
    async for raw in ws:
        msg = json.loads(raw)
        if msg.get("type") == "key":
            await ws.send(json.dumps(TURN, ensure_ascii=False))

async def main():
    async with websockets.serve(handler, "127.0.0.1", 8090):
        print("mock ws: ws://127.0.0.1:8090")
        await asyncio.Future()

asyncio.run(main())
~~~

本骨架在 Python 3.12 + websockets 15 下已跑通：客户端发一条 key 消息，收到一条 turn_result，中文不乱码。起服务后另开窗口自检：

~~~powershell
python tools/mock_ws.py
websocat ws://127.0.0.1:8090 -t
# 粘贴：{"type":"touch.event","session":"s_001","target":"primary","action":"tap"}
~~~

### 步骤 6 的数值，别把 pt 当 px

**屏内控件**

| 控件 | `target` | 尺寸 | 上行 |
| --- | --- | --- | --- |
| 主操作按钮 | `primary` | 通栏 ≥72px 高 | `touch.event { target: "primary", action: "tap" }` |
| 选项胶囊 | `option:<slot_id>` | ≥88px 高 | `touch.event { target: "option:<slot_id>", action: "tap" }` |

**设置面板**（顶栏 ⚙ 进入）：音量、语速、方言、高对比、助听器、陪伴开关 —— 全部本地生效，不上行。

硬性规格：最小点击区 **88×88 CSS px**，控件间距 ≥16px，正文 ≥24px。**不依赖任何手势**（不滑动切页、不双击、不双指、不长按），全部是单击。

约束：控件只发命令，不改状态。状态由服务端 `state.transition` 推进（I1 不变量）。W1 阶段没有服务端，就先写一个 `dispatch(target, action)` 的壳，把调用打到 console。

### 步骤 4 的做法

~~~javascript
// store/episode.js
import { defineStore } from "pinia";

export const useEpisodeStore = defineStore("episode", {
  state: () => ({ episodeId: null, status: "ARRIVED" }),
  actions: {
    select(id) { this.episodeId = id; },
    transition(to) { this.status = to; },
  },
});
~~~

验收动作：在 `REGISTER` 屏按一次「返回」，再进 `WAITING`，顶栏显示的 `episodeId` 还是同一个，`status` 是 `WAITING`。

### 步骤 4：mock HTTP 的骨架（零依赖）

~~~python
import json
from http.server import BaseHTTPRequestHandler, HTTPServer

BODIES = {
    "/api/v1/health": {"ok": True, "version": "w1"},
    "/api/v1/episodes/ep_001": {"id": "ep_001", "status": "ARRIVED", "staff_contact": "stf_01"},
}

class H(BaseHTTPRequestHandler):
    def do_GET(self):
        body = BODIES.get(self.path.split("?")[0])
        if body is None:
            self.send_response(404); self.end_headers(); return
        data = json.dumps(body, ensure_ascii=False).encode()
        self.send_response(200)
        self.send_header("Content-Type", "application/json; charset=utf-8")
        self.send_header("Access-Control-Allow-Origin", "*")
        self.end_headers()
        self.wfile.write(data)

HTTPServer(("127.0.0.1", 8000), H).serve_forever()
~~~

这个骨架在 Python 3.12 下已跑通，两个路径都返回 200 且带 CORS 头。**那一行 CORS 必须留**，三个前端分别跑在 5173 / 5174 / 5176，跨端口请求没有它浏览器会拦掉，T3、T4 会以为是自己写错了。
