# 00 · 术语表

> 全项目统一语言。违反本表的合并请求予以退回。

| 术语 | 代码名 | 定义 | 禁止叫法 |
| --- | --- | --- | --- |
| 陪诊单 | \`Episode\` | 一次完整的陪诊服务过程（从出发前到回家后） | 订单、任务、case |
| 会话 | \`Session\` | 设备与用户的一次连续对话 | 对话、chat |
| 留痕 | \`Timeline\` / \`Media\` | 过程记录（时间/照片/录音/凭证） | 日志（日志专指 AuditLog） |
| 复述校验 | \`RecallCheck\` | 让用户复述一遍以确认听懂 | 确认、核对 |
| 兜底 | \`Fallback\` | 任何一步卡住时的降级处理路径 | 异常处理 |
| 升级 | \`Escalation\` | 从 AI 移交给人的动作（叫护士 / 打电话给家属） | 报警 |
| 陪诊师 | \`Companion\` | 真人陪诊服务人员 | 护士、护工 |
| 红线校验器 | \`Guard\` | 拦截越界话术的规则组件 | 过滤器 |
| 证据链 | \`EvidenceChain\` | 一句话从事实到出口的五段生成记录 | 日志 |
| 无障碍档案 | \`AccessibilityProfile\` | 视力/听力/认知/行动/识字能力的结构化记录 | 残疾信息 |
| 交接双签 | \`Handover\` | 重要医疗材料交接时的双方签名与存证 | 签收 |
| 置信度 | \`Confidence\` | 识别或意图判断的可信程度，取值 0–1 | 准确率（两者不可混用） |
| 灰度 | \`Canary\` | 新适配器先对小流量生效 | 测试版 |
| 假适配器 | \`FakeAdapter\` | 测试与本地开发用的确定性实现 | mock（代码中统一用 Fake 前缀） |
