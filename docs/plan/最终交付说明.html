05质量红线与不做清单

三条强制性约束（不得放宽）
  1. 医学相关表述须以医生原话为来源，不得表述为系统判断
  2. 识别不确定时须标记并求证，不得推断，剂量字段尤须遵守
  3. 重要医疗材料须电子化留存并完成交接双签
不可突破的质量门槛
  • 禁用词出现次数 = 0
  • OCR 剂量字段错误数 = 0
  • 领域层单元测试覆盖率 = 100%
  • 测试用例总数：W2 ≥ 40 → W8 ≥ 240
  • AI 评测集：W6 ≥ 120 → W8 ≥ 200
明确不做的六项（已从范围排除）
  1. 微信小程序上架 —— 需企业主体与审核周期，改用 H5 + 测试号
  2. 原生 App（Android / iOS）—— 用 H5 替代
  3. 嵌入式驱动 / LVGL 界面 / 自研 PCB —— 设备端是网页，硬件只做按键与震动
  4. 医院 HIS 系统对接 —— 无法获得授权
  5. 多医院覆盖 —— 只做一个场景做深
  6. 端侧大模型 —— 平板跑不动，全部走服务端 API
