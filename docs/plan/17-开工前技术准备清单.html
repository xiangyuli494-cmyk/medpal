01优先级定义

先看这张表，决定每一项要花多少时间。
等级含义时间投入判定标准
A 必须会 W1 – W2 立刻要用，不会就直接卡住 开工前必须完成 能独立写出最小可运行示例，无需旁人指导
B 边做边学 W3 – W5 会用到 开工前只需知道概念与查法 知道它解决什么问题、文档在哪、遇到时能查
C 用时再查 特定条件下才触发 不投入，需要时当天学 知道存在这项技术即可
一条重要提醒：不要系统性学完任何一个框架。Vue 官方教程 30 多节、Django 官方教程 7 部分， 全学完要 30 小时以上，八周项目负担不起。按本清单的 A 级条目学最小子集，其余遇到再查。

05不建议花时间学的

这些技术看起来相关，但本期用不上或性价比极低，学了是浪费。
以下六项明确不要学
  1. Docker / Kubernetes —— 本期部署到一台服务器，直接装环境即可
  2. Neo4j Cypher / 图数据库运维 —— 知识图谱是条件交付 C2，且由成员 A 的模块提供
  3. Milvus / 向量检索 / RAG 原理 —— LLM+RAG 是条件交付 C1，不在主链路
  4. Vue 官方教程全 30 节 —— 只学 Composition API 与组件，其余现查
  5. Django 源码 / 中间件机制 —— 会用视图和 ORM 就够
  6. 微信小程序开发 —— 本期不做（需企业主体）
