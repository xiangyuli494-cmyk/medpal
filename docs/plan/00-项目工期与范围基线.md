# 项目工期与范围基线（v3.0 · 八周）

> 本文件是全部规划文档的唯一口径基准。任何文档与本文件冲突时，以本文件为准。
> 变更基线须经 T1 裁决并更新本文件版本号。

---

## 1. 工期

| 项 | 内容 |
| --- | --- |
| 项目周期 | **8 周**（W1 – W8），自项目启动周起算 |
| 工作日 | 仅周末有效工作：周六 19:00–22:00（集成、联调、验收）、周日 19:00–22:00（开发、评审、周报） |
| 有效投入 | 每人每周 4 – 8 小时；6 人每周合计 24 – 48 人时；8 周合计 192 – 384 人时 |
| 排期最小单位 | **周** |
| 缓冲 | 每个里程碑周预留半个周末（周日 20:00 后）用于缺陷清扫 |
| 考试周 | 本项目周期内不预设考试周；如遇临时考试，当周工作量按 50% 计并顺延对应任务至下一周，不得压缩里程碑 |

## 2. 阶段与里程碑

| 阶段 | 周次 | 主题 | 里程碑 | 验收标准 |
| --- | --- | --- | --- | --- |
| P0 | W1 | 立项、契约冻结、基础设施 | — | CI 可执行；会话协议 v0.1 冻结；领域模型 v0.1 冻结；术语表 |
| P1 | W2 | 领域内核与四端骨架 | M1 | 四端骨架可启动；领域层纯函数单测覆盖率 100%；测试数 ≥ 40 |
| P2 | W3 – W4 | 主线闭环（假适配器） | M2 | 9 状态节点全通；测试数 ≥ 120；E2E ≥ 8 条 |
| P3 | W5 – W6 | 真实 AI 接入 + 四端成型 | M3 | 真 ASR/TTS/OCR 可用；剂量字段零错误；评测集 ≥ 120 条 |
| P4 | W7 – W8 | 用户测试、交付、答辩 | M4 | 真人可用性测试 ≥ 10 人；测试数 ≥ 240；演示无人工干预 |

| 排除项 | 理由 |
| --- | --- |
| 微信小程序上架 | 需企业主体与审核周期，改用 H5 + 测试号 |
| 医院 HIS 系统对接 | 无授权 |
| 多医院覆盖 | 限定单一场景 |

| 自研 PCB、注塑外壳 | 工期不允许 |

## 4. 硬件策略（关键决策）

| 项 | 决策 |
| --- | --- |
| 主演示载体 | **平板或笔记本浏览器**，运行同一套 Web 前端；W2 起可演示，不依赖采购 |
| 物理硬件 | 定位为**加分项**，仅演示"按键触发 + 震动反馈"，不承担主流程演示 |
| 采购时点 | W1 当周下单；W6 未到货即放弃 C3、C4，不影响 M3、M4 |
| 保底方案 | 双机备份（笔记本 + 平板），离线单文件演示包 |
