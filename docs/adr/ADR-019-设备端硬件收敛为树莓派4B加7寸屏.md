# ADR-019 设备端硬件收敛为树莓派 4B + 7 寸屏

- 状态：已接受（W1）
- 日期：W1
- 决策人：T2（提出），T1、T4 会签
- 关系：取代 ADR-018 的硬件段（机身五个实体键、3D 打印外壳、读卡区、整机 380 克、C3 震动模块与 C6 外壳）。ADR-018 的「手持借出式、7 寸 1024×600 横屏、服务台借出与离院归还」四条继续有效。
- 影响范围：`docs/specs/device-ia.md`、`docs/specs/access-control.md`、`docs/api/ws-protocol.md`、`docs/adr/ADR-018-设备端形态为手持借出式.md`、`docs/plan/00`、`docs/plan/01`、`docs/plan/02`、`docs/plan/10`、`docs/plan/11`、`docs/plan/18-W1周任务包.md`、`docs/plan/18-技术栈总览.html`、`docs/plan/19-W1逐人操作手册.md`、`docs/plan/一图看懂-要做什么.html`、`docs/qa/requirement_issues.md`、`demo/`

---

## 1 背景

ADR-018 定形态时，硬件是按「能买到什么就写什么」写的理想配置：五个实体键、3D 打印外壳、背面读卡区、震动马达。到 W1 实际下单，手上的件只有两件与交互有关：

- 树莓派 4B（4GB）+ 亚克力风扇外壳 + 32GB TF 卡 + Type-C 开关电源 + Micro-HDMI 线 + 1m 网线 + 散热片 + 入门手册
- 亚博智能 7 寸 1024×600 IPS 电容触摸屏（HDMI 接口）

没有按键模块，没有震动马达，没有读卡器，没有电池，没有外壳开模能力。麦克风与扬声器也还没选型。原文档里的「五个实体键」「3D 打印外壳」「读卡区在机身背面」「震动编码」四项，在实物上都不存在。

文档与实物不一致的代价是可验证的：验收要按文档走，答辩要按文档讲，而演示件一开机就露馅。必须在 W1 把口径砍到实物上，而不是留到 W6 到货判定时再说。

## 2 备选方案

| 方案 | 内容 | 判断 |
| --- | --- | --- |
| A | 保留 ADR-018 全部硬件，W6 前补齐按键模块、震动马达、读卡器、外壳 | 否决。八周内采购与结构件不受团队控制；按键、震动、读卡都要改设备端与协议，是纯增量的返工 |
| B | **把硬件收敛到已到货的两件，交互全部落回屏幕，删除依赖不存在的硬件的能力** | **采纳** |
| C | 硬件不写，文档里只说「便携终端」 | 否决。设备端七分区、88×88 点击区、横屏预算都依赖具体尺寸，不写尺寸等于没有设计依据 |

## 3 决策

1. **硬件清单只有七项**：树莓派 4B（4GB）、7 寸 1024×600 IPS 电容触摸屏、亚克力风扇外壳（含风扇）、32GB TF 卡与读卡器、Type-C 开关电源（5V/3A）、Micro-HDMI 线与 1m 网线、散热片。麦克风与扬声器**型号未选定**，选型前语音入口以触摸等价路径替代（`speak` 分支的文本输入与预置短语）。

2. **不设实体按键。** ADR-018 的五个实体键（电源、音量－、音量＋、按住说话、一键求助）全部取消。电源由 Type-C 开关电源上的物理开关承担，不进交互设计；音量、语速收进顶栏齿轮的设置页，只在本机生效；按住说话与一键求助改为屏内入口（`mic`、`sos` 两个 `touch.event` target 保留，位置在全屏主操作或选项胶囊上）。

3. **不带电池。** 整机取电走 Type-C 开关电源，无续航指标，无电量显示。顶栏左侧由「点位 · 电量 · 时间」改为「点位 · 时间 · 联网状态」。使用场景限定在有插座的服务台与候诊区，借出时由服务台接通电源。

4. **无读卡器。** 取消刷证建档与背面读卡区。借出由服务台登记，老人报姓名与年龄段，值班人员代为录入；设备端不采集证件号，也不显示证件号。`docs/specs/access-control.md` 的六位绑定码兜底路径保留，读卡器从「真机接入」改为「不设」。

5. **不使用蓝牙信标。** 取消 B-01 至 B-08 的 beacon 触发与 `device/src/content/spots.ts` 的编号资产。八处点位讲解改为：老人在屏上自己选点位，或由服务台在借出时设好起点；点位切换是屏内动作，上行 `touch.event { target: "spot", action: "tap" }`，不依赖室内定位。点位讲解词本身保留（八条），只是触发方式从「到点自动」改为「选点即讲」。

6. **取消震动马达与 3D 打印外壳。** 条件交付 C3（震动触觉模块）与 C6（3D 打印外壳）整项取消，C4（整机）的范围收窄为「树莓派 + 屏 + 亚克力外壳」。震动编码的语义（确认、出错、该走了）不删，改为字幕条上的文字与图标提示。

7. **归还闭环写成产品动作，并给出删除回执。** 归还时设备端清空本机记录（行程、用药、检查结果、录音与照片、绑定信息），屏幕逐条列出已删除项，并给出一张带回执号的删除回执。这是 ADR-018「离院即清」的落地形式，此前只有描述、没有回执。

8. **文档与实物一致性优先于功能完整度。** 凡依赖未到货硬件的描述，一律从「已具备」改为「不设」或「型号未选定」，不留「到货后启用」的悬念句——悬念句在验收时会被读成承诺。

## 4 依据

1. **实物决定口径。** 已到货的只有树莓派 4B 与 7 寸屏，其余件不在采购清单里。文档写五个实体键，验收时无法演示，也无法交付。
2. **屏内入口足够。** 七分区已经把主操作做成全屏最大的按钮，选项胶囊最多三个；对目标用户（低视力、不会用智能手机的老人），一个 88×88 以上的屏内按钮比机身上的小键更容易命中。ADR-017 否决 12 键方案的理由在这里同样成立。
3. **无电池反而降低风险。** 带电池要引入充电管理、续航指标、电池安全与运输限制；开关电源是标准件，坏了换一根线。使用场景本来就在院内，插座不是稀缺资源。
4. **无信标解决了一个 ADR-018 自己记下的矛盾。** ADR-018 §1 已经写明：固定在门诊大厅的机器只能触发自己所在的那一个点位，B-02 至 B-08 永远到不了。改为屏上选点后，八个点位都能讲，且不需要 BLE 硬件与点位布设。
5. **删除回执把「离院即清」变成可交付物。** 只写「清空」无法证明清空了；一张带回执号、逐条列项的删除回执，是能拿给患者看、也能写进验收的东西。
6. **成本可控。** 树莓派 4B 套件 1086.82 元、7 寸 1024×600 IPS 触摸屏 219 元，两项合计 1305.82 元；取消外壳开模与震动模块后，单台物料即为此数，不再有「1500 元上下」的浮动。

代价有三项，写进方案时要一并说明：

1. **语音是唯一「不看屏」的入口，而麦克风未选型。** 在麦克风到位前，语音能力只能由浏览器 `getUserMedia` 与文本输入顶替；「按住说话」这个不看屏的动作暂时不存在。选型完成前，验收不设语音相关指标。
2. **无电池把使用场景钉在插座附近。** 借出范围实际是「服务台、候诊区、诊区走廊带插座的段落」，跨楼层长距离移动要拔电，这一条要写进借还说明。
3. **删除回执是新增产品物件。** 需要回执号的生成规则、打印或截图方式、以及院方是否留存一份。当前按「屏幕展示 + 老人可拍照」处理，不接打印。

## 6 八周工期下的影响

本条不新增工作量，净减少。删掉 C3 与 C6 后，T2 在 W6–W8 的硬件挂点全部释放，转而做设备端镜像、开机自启与双机备份。设备端逐屏骨架仍按 1024×600 横屏在 W2 开始，平板与笔记本浏览器仍是验收载体，演示件与真机共用同一套 1024×600 布局。
