## 使用规则

1. **一条一个 PR。** 拆不动的（如 F-019）在 Issue 里标「需再拆」并单独讨论，不要硬塞。
2. 标题进看板时保持编号不变，只允许补充验收标准。改编号等于换需求。
3. 里程碑是计划值，实际顺延在周会上改，改完同步本表。
4. 新增需求从 F-041 起编号，不插队。
