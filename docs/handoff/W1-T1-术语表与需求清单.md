## 一句话说清它干什么

把词定死、把需求拆成四十条能一个 PR 做完的标题。

## 数据流

术语表是命名权威：标识符先在这里登记，才允许出现在 `backend/`、`frontend/`、`device/` 里。需求清单是工作来源：每条 `F-0xx` 对应一个分支 `feat/F-0xx-简述`，分支再对应一个 PR，PR 模板要求术语与本表一致。

~~~mermaid

  T[docs/00-术语表.md] -->|标识符唯一来源| C[代码 backend/frontend/device]
  T -->|一致性检查| P[PR 模板]
  B[docs/specs/backlog.md] -->|F-0xx| BR[分支 feat/F-0xx]
  BR --> PR[PR]
  P --> PR
~~~
