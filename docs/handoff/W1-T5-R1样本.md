# 模块：R1 合成样本与资产卡

## 一句话
一条命令生成 60 份三类合成样本及对应 Asset Card，满足 W1 里程碑「≥60 份资产入库并生成卡片」。

## 数据流
gen_samples.py → 循环 5 个病种模板 → 写 text/*.md、table/*.csv 与 .xlsx、image/*.png → 每份生成 AST-* 资产卡（含 anchors）→ 落进 agent/data/asset-cards/ 供 ingest_asset 消费。

## 我改了什么（人工修改点）
- 图文样本用 PyMuPDF 渲染成 PNG，中文走 china-s 字体，渲染失败时退回 ASCII 避免整批中断。
- 卡片字段严格按 mcp-contract §2.1，锚点按 §1.2 的四种模态编码；全部标 synthetic、敏感级 public。
- 表格类用「一份参考区间表 + 19 份门诊记录」凑够 20 份，卡片里写明来源是同一份表的不同行段。

## 怎么验证的
运行 `python agent/tools/gen_samples.py` 输出「文本 20 / 表格 20 / 图文 20 / 合计 60 / 卡片 60 张」且退出码 0；抽检文本卡锚点为 `#s2`、图文卡为 `#img.r1`，与契约一致；`python -B -m agent.skeleton` 仍输出 OK 5 steps；`ruff check .` 全仓通过。
