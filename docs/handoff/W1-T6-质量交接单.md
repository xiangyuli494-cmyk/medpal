## 一句话说清它干什么
为本项目搭建CI质量门禁流水线、分支保护规则与基础pytest测试骨架，提交PR时自动执行代码检查、禁用词扫描、单元测试。

## 数据流
PR提交触发GitHub Actions → 拉取仓库代码 → 执行ruff代码规范检查 → 执行禁用词扫描检查 → 执行pytest单元测试

## 我改了什么（人工修改点）
1. 配置仓库分支保护，禁止直接推送main分支，强制走PR评审流程
2. 新增.github/workflows/ci.yml，搭建lint-and-test CI流水线，包含ruff、禁用词检查、pytest
3. 新增tests/test_demo.py，搭建基础测试骨架，提供可运行示例用例，支持覆盖率采集
4. 补充本模块交接单，放到docs/handoff目录，满足handoff门禁校验

## 怎么验证的
1. 本地执行make test，pytest正常运行，输出测试覆盖率，退出码为0
2. 推送分支触发PR，CI流水线自动执行全部检查项，全部任务绿灯通过
3. handoff脚本扫描docs/handoff下本交接单，格式校验无报错
4. 分支保护规则生效，无法直接向main分支push代码
