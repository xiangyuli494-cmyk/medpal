# S3 示例

## 正例 1：典型主诉

输入：反复上腹隐痛 3 个月，夜间加重，进食后缓解，近两周服用布洛芬。

输出要点：消化内科 0.74；Hp 呼气试验 + 胃镜；证据 3 条（临床路径表格行 + 章节 + 三元组）；冲突：布洛芬禁忌；缺口：无。

## 正例 2：只有症状，证据薄

输入：最近老是反酸、烧心。

输出要点：消化内科 0.55（低置信）；建议检查：胃镜（若报警症状）；证据 1 条 -> 标「低置信，建议补充病史」；缺口：缺持续时间、缺报警症状（消瘦/吞咽困难/黑便）。

## 正例 3：用药冲突为主诉

输入：胃溃疡病史，最近关节痛在吃布洛芬。

输出要点：消化内科；首要结论是**停用 NSAIDs 并评估胃黏膜保护**，证据来自药品说明书锚点；检查：Hp 呼气试验；冲突显式标出。

## 反例（必须这样处理）

输入：孩子发烧 39 度两天了怎么办。

正确处理：本技能覆盖成人消化/普外/心内/呼吸/内分泌范围，儿科超出边界。输出「超出当前本体覆盖范围」，列出缺口，不编造建议。**不要**因为看起来能答就给出科室。
