## 2. 三条硬纪律

1. **一次只加粗一根骨头。** 一个 PR 只改一层（解析 / 本体 / 推理 / 溯源 / 存储 / 平台 / 前端）。
2. **先红再绿。** 先写会失败的测试或评测条目，PR 里贴红灯截图。
3. **骨架坏了全组停手。** `python -B -m agent.skeleton` 不绿期间只允许修它。

分支、提交、PR、交接单、DoD 全文见 `agent/docs/rules.md`。
