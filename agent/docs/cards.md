# 讲解卡（Trace可视化答辩卡片）
> 用于答辩，评委快速看懂推理可视化模块

## 卡1：是什么
本模块是推理轨迹可视化页面（trace.html），输入trace推理日志json文件，自动渲染出最多5步的决策链路；
高亮展示推理用到的证据，推理路径断裂时节点标红提示。
定位：把机器的黑盒推理日志，转化成评委30秒内可以读懂的可视化图表，不包含后端逻辑，纯静态前端页面。
输入：trace.json推理轨迹文件
输出：可视化决策链页面

## 卡2：为什么可信
1. 可视化完全基于原始trace.json原样渲染，不会篡改推理步骤与证据文本；
2. 遵循T1给出的trace-schema规范解析，字段映射单独抽离，和底层推理输出格式对齐；
3. 通用性：支持任意合规trace文件、不同起点重跑的推理结果，渲染逻辑统一；
4. 断链标记自动识别推理缺失节点，直观暴露推理链路漏洞，方便校验推理完整性。

## 卡3：怎么进化
v0版本（当前）：5步固定长度决策链、证据高亮、断链标红，满足基础答辩评审；
v1版本规划：
1. 支持更多步数自动折叠/展开；
2. 增加节点hover详情弹窗，展示完整元信息；
3. 和本体视图联动，跳转本体差异对比页面；
4. 增加导出图片功能，方便答辩存档。
