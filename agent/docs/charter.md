# 一页纸章程 · 赛题3 可进化决策智能体

> 版本 v1.0 · 2026-10-22 · 冻结后不再改第 1–4 节
> 团队：T1 契约架构 / T2 知识推理 / T3 交互可视化 / T4 本体演化 / T5 解析检索 / T6 质量环境

---

## 1. 一句话

**给行业数据装一个会自己长大的知识库，并且它每一次判断都能指回原文哪一句。**

## 2. 谁用、用来干什么

不是给患者用的 App，是给**业务系统调用**的认知中台。

| 场景 | 输入 | 输出 |
| --- | --- | --- |
| 临床路径问答 | 一份 20 页 PDF 路径文档 | 「这病要做什么检查」+ 每条依据的原文位置 |
| 跨文档推理 | 三份不同年份的指南 | 「新版把这条推荐降级了」+ 两处原文对照 |
| 标准对齐 | 院内术语 | 映射到 ICD-10 / 临床路径标准条目 |

## 3. 交付物（可验证）

| # | 东西 | 怎么验 |
| --- | --- | --- |
| 1 | 一条命令跑通全链 | `python -B -m agent.skeleton` 退出码 0 |
| 2 | 本体能从文档抽 | 给一份没见过的文档，抽出 ≥8 个三元组，每条指得到原文 |
| 3 | 本体能版本化 | `--diff v0.9 v1.0` 输出增删改三类 |
| 4 | MCP Server 7 个工具 | Nexent 里能看到、能调通 |
| 5 | 3 个 Skill 工作流 | 端到端跑一次，产出可复用模板 |
| 6 | 决策链可溯源 | 任意结论能展开成「结论 → 证据 → 原文位置」 |
| 7 | 评测集 30 条 | 六指标 + 与上一版对比 |
| 8 | 开源仓库 | GitCode 可访问，无 Key 无患者数据 |

## 4. 明确不做（写下来是为了不吵）

- **不做硬件**，不做设备，不做屏幕，不做语音交互
- **不做患者端 UI**（演示用的 trace 可视化不算产品界面）
- **不做多租户、不做权限体系、不做计费**
- **不接真实医院 HIS**，数据全部用合成/公开样本
- **不做模型训练**，一律走 API
- **不做图数据库**，SQLite 单文件够用
- **不追 SOTA**，比赛看的是链路完整与可溯源，不是榜单分数

> 任何一条想加回来，都要在周会上过，并说清砍掉哪一条等量的东西。

## 7. 失败时的降级顺序

从下往上砍，砍到能交付为止：

1. 砍 OCR（扫描件不支持）
2. 砍三跳（退回两跳）
3. 砍标准对齐（只做映射表不写代码）
4. 砍 Skill 数量（3 → 1）
5. 砍可视化（退回 trace.json 原文展示）

**永远不砍的**：一条命令能跑、每条结论有原文依据、能装在 Nexent 上。
