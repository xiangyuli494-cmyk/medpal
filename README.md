# 小暖陪诊

> 面向就医困难人群的陪诊服务系统 · 六人团队 · 八周工期

一个陪一个不会用手机的老人走完一次医院全流程的服务系统。会用手机的人走 App / 小程序，家属走微信，陪诊师走工作台，老人走设备端 —— **四端同一个内核**。

## 三条强制性约束

| 编号 | 约束 |
| --- | --- |
| R-1 | 医学相关表述须以医生原话为来源，不得表述为系统判断 |
| R-2 | 识别不确定时须标记并求证，不得推断，剂量字段尤须遵守 |
| R-3 | 重要医疗材料须电子化留存并完成交接双签 |

## 五条开发纪律

1. 先编写规格说明，再编写测试，最后交由 AI 生成实现；缺少规格与测试的代码不得合并至 main。
2. 单次 AI 生成任务规模不超过 300 行、不超过 1 个模块。
3. AI 生成的代码须由另一名成员进行实质性修改后合并。
4. T6（质量保证）拥有合并否决权；缺少测试的合并请求一律退回，对项目经理同等适用。
5. 每名成员均为单点故障风险；W2、W5 各执行一次互备演练。
