# backend/domain —— 领域层

纯 Python，零框架依赖。状态机、话术模板、红线校验、检查规划都在这一层。

## 三条约束

1. 不许 import django、requests、sqlalchemy、任何 SDK（CI 会自动查）；
2. 不许读写数据库、不许发网络请求；
3. 单元测试覆盖率 100%，差一行都算没做完。

## 为什么这么严

这一层是四端共用的内核，也是最容易被 AI 写乱的地方。它一旦依赖框架，测试就要起数据库，跑一次几十秒，覆盖率也就没法保证了。

## 目录约定

| 目录 | 放什么 |
| --- | --- |
| domain/state/ | 陪诊状态机与跃迁校验 |
| domain/talk/ | 话术模板与槽位渲染 |
| domain/guard/ | 红线校验器 |
| domain/plan/ | 检查规划打分 |

W2 开始按这个顺序写：状态机 → 话术 → 红线 → 规划。
